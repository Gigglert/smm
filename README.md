Планер для СММ

## Из чего состоит

- `index.html` — разметка страницы: вкладки и окна карточек.
- `css/style.css` — внешний вид.
- `js/` — логика, файлы подключаются строго по порядку:
  - `data.js` — каналы, рубрики, значения по умолчанию, загрузка состояния;
  - `storage.js` — сохранение в браузере и в облаке (Supabase), история версий, файл-копия;
  - `nav.js` — вкладки и календарь контент-плана;
  - `boards.js` — «Разработка контента (стадии)», «Доска задач», спринты, колонки;
  - `cards.js` — окна карточек: пост, задача (с копированием в спринт), ресурсы;
  - `sheets.js` — таблицы «Идеи» и «Гипотезы по HADI», связка идей с разработкой;
  - `app.js` — общие помощники и запуск; подключается последним.

## Автопроверки

`tests/planner.test.js` открывает планер в настоящем браузере и прокликивает все функции.
Облако в проверках отключено, реальные данные не трогаются.

Проверки запускаются сами в GitHub при каждой правке (вкладка Actions).
Запустить вручную: `npm install`, затем `npm test`.
